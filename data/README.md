# Dataset

El archivo CSV no está incluido en este repositorio por licencia de Kaggle.

## Cómo descargarlo

**Opción A — Automática (recomendada):**
El notebook descarga el dataset automáticamente en la Sección 2
usando `kagglehub`. Solo necesitás tener configurado tu token de Kaggle.

**Opción B — Manual:**
1. Ir a: https://www.kaggle.com/datasets/nicapotato/womens-ecommerce-clothing-reviews
2. Descargar `Womens Clothing E-Commerce Reviews.csv`
3. Colocar el archivo en esta carpeta `/data/`

## Sobre el dataset

- 23.486 registros de reseñas de clientes de e-commerce de ropa
- Variables principales: Review Text, Rating (1–5), Recommended IND
- Fuente: Kaggle — licencia pública para uso educativo
